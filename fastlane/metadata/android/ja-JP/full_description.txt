<p>Marmalade TTS で、スマートフォンの読み上げが、聞きたくなる声に変わります。テキスト読み上げエンジンに設定すると、スクリーンリーダーから電子書籍リーダー、チャットアプリまで、読み上げに対応したすべてのアプリが Marmalade の声で話します。自然なボイスは、スマホの中でオフラインで動作します。</p>

<p><b>9 言語に対応</b></p>
<p>多言語エンジンの Kokoro は英語（米国・英国）、スペイン語、フランス語、イタリア語、ポルトガル語（ブラジル）、ヒンディー語、日本語、中国語（標準語）を話します。読みながら言語を判別して発音をその場で切り替えます。Kokoro German を追加するとネイティブのドイツ語ボイスも使えます。</p>

<p><b>どのアプリでも</b></p>
<p>Marmalade は Android 標準のテキスト読み上げ設定に組み込まれるため、この仕組みで話すアプリは、どれも Marmalade の声で話します。設定で一度 TTS エンジンとして選ぶだけです。</p>

<p><b>インストールしてすぐ使える</b></p>
<p>Marmalade には高速な英語ボイスが内蔵されているので、初めて起動したときから、オフラインでテキスト読み上げが使えます。ほかの言語は、一度ダウンロードするだけで使えます。より大きく高品質なエンジンは、選んだときだけダウンロードされ、その後はやはりオフラインで動作します。</p>

<p><b>アプリごとに違うボイス</b></p>
<p>Marmalade の中心にあるのは「エイリアス」です。お気に入りのボイスを、速度とエフェクトの設定と組み合わせて作れます。アプリをエイリアスに割り当てれば、電子書籍リーダーはあるボイスで、チャットアプリは別のボイスで話せます。割り当てていないアプリは、メインのエイリアスを使います。</p>

<p><b>クラウドを使っても、使わなくても、プライベート</b></p>
<p>アナリティクスもテレメトリーもアカウントもなく、私たちが運営するサーバーもありません。端末内のボイスがネットワークを使うのは、選んだエンジンをダウンロードするときだけです。スマホで動かせる以上のボイスがほしいときは、ご自身の API キーでクラウドプロバイダのボイスを追加できます。Venice.ai のように、リクエストを保存も記録もしないとするプロバイダもありますが、記録する場合もあるため、各社のプライバシーポリシーをご確認ください。クラウドプロバイダを設定するまで、読み上げる内容がスマホの外に出ることはありません。</p>

<p><b>ウェブ記事を読み上げ</b></p>
<p>リンクを Marmalade に共有すると、記事をすっきりしたリーダー表示で開き、読んでいる段落をハイライトしながら読み上げます。記事ごとに、読み上げるボイスと速度を選べます。アクセスするのは共有したページだけで、画像やトラッカーは読み込まず、何も保存しません。</p>

<p><b>スクリーンリーダーのために</b></p>
<p>TalkBack などのスクリーンリーダーを支える読み上げエンジンとして、Marmalade を使えます。アプリ自体も TalkBack に対応し、WCAG 2.1 AA を満たすよう設計されています。ダークテーマは AA のコントラスト基準を満たします。TalkBack が有効なときは、進行状況やエラーを音声でお知らせします。</p>

<p><b>自分好みに</b></p>
<p>「8-bit」「Cyborg」「Megaphone」「Vintage radio」など、20 種類以上の組み込みエフェクトプリセットで、読み上げに個性を加えられます。エディタで、自分だけのエフェクトチェーンを作ることもできます。速度は半分から 2 倍まで自由に設定でき、ボイスは自然な響きを保ちます。</p>

<p><b>長い文章も</b></p>
<p>画面を消しても長い文章の音声読み上げが続き、ロック画面や Bluetooth から操作できます。どのアプリからでもテキストを共有するか、テキストを選択して「Marmalade で読み上げ」を選んでください。</p>
