<p>Marmalade TTS は、あなたのスマートフォンに聴きたくなる声を与えます。システムのテキスト読み上げエンジンに設定すれば、スクリーンリーダーから電子書籍リーダー、チャットアプリまで、読み上げを行うすべてのアプリが Marmalade の声で話します。</p>

<ul>
<li><b>自然なニューラル音声。</b>インストールしたその瞬間から話せます</li>
<li><b>高速。</b>控えめなスペックの端末でもすばやく応答します</li>
<li><b>プライバシー重視。</b>すべての処理が端末内で完結します</li>
<li><b>クラウド音声にも対応（任意）。</b>ご自身の API キーでプライバシーに配慮した外部サービスを利用できます（Venice.ai）</li>
<li><b>アプリごとの音声。</b>アプリ単位で使う声を割り当てられます</li>
<li><b>8 言語に対応。</b>Kokoro TTS エンジンなら読み上げ中の言語を自動で判別します</li>
<li><b>アクセシビリティ対応。</b>TalkBack に対応し、WCAG 2.1 AA を満たす設計です</li>
<li><b>ボイスエフェクト。</b>22 種類のプリセットに加え、自作用のエディタも搭載</li>
<li><b>無料、オープンソース、広告なし、アカウント不要</b></li>
</ul>

<p><b>どこでも使えます</b></p>
<p>Marmalade は Android 標準のテキスト読み上げインターフェースに準拠しているため、Google や Samsung の TTS をそのまま置き換えられます。設定で一度選ぶだけで、さまざまなアプリの読み上げを Marmalade が担当します。</p>

<p><b>インストールしてすぐ使えます</b></p>
<p>高速な英語音声を内蔵しているので、初回起動からオフラインで読み上げできます。より大きく高品質なエンジンは、選んだときにだけダウンロードされます。端末内の音声で読み上げたテキストがスマートフォンの外に出ることはありません。</p>

<p><b>アプリごとに違う声を</b></p>
<p>Marmalade はエイリアスを中心に設計されています。速度やエフェクトを調整してお気に入りの声を作り、アプリをエイリアスに割り当てれば、電子書籍リーダーはひとつの声で、チャットアプリは別の声で読み上げられます。割り当てのないアプリは、メインのエイリアスに従います。</p>

<p><b>8 言語に対応</b></p>
<p>多言語対応の Kokoro エンジンは、英語（米国・英国）、スペイン語、フランス語、イタリア語、ポルトガル語（ブラジル）、ヒンディー語、日本語、中国語（標準中国語）を話します。読み上げながら言語を判別し、発音をその場で切り替えます。</p>

<p><b>クラウドを使っても、使わなくてもプライベート</b></p>
<p>アクセス解析もテレメトリーもアカウントもなく、私たちが運営するサーバーもありません。端末内の音声がネットワークに接続するのは、選んだエンジンをダウンロードするときだけです。スマートフォンだけでは実現できない声が欲しい場合は、ご自身の API キーでクラウドエンジンを追加できます。提供元には、リクエストの保存もログ記録も行わないとしている Venice.ai などがあります。設定しない限り、読み上げた内容がスマートフォンの外に出ることはありません。<i>注：他の提供元はリクエストをログに記録する場合があります。各社のプライバシーポリシーをご確認ください。</i></p>

<p><b>スクリーンリーダーのために</b></p>
<p>Marmalade は TalkBack に手厚く対応し、高コントラストのダークテーマとともに WCAG 2.1 AA を満たすよう設計されています。すべての操作にラベルが付き、TalkBack が有効なときは進捗やエラーを音声でお知らせします。支援技術を使う方に必要な機能が、購入の先に隠れていることはありません。</p>

<p><b>自分好みに</b></p>
<p>8-bit、cyborg、megaphone、vintage radio など 22 種類の組み込みエフェクトプリセットが、読み上げに個性を加えます。エディタで自分だけのエフェクトチェーンを組むこともできます。</p>

<p><b>長い文章もしっかり</b></p>
<p>フォアグラウンド再生サービスが、画面を消したままでも長文を安定して読み上げます。ロック画面や Bluetooth からの操作にも対応。どのアプリからでもテキストを共有したり、システムの「選択して読み上げ」を使ったり、クイック設定タイルからクリップボードを読み上げたりできます。</p>
