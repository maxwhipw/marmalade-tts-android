<p>Marmalade TTS 让你的手机拥有一把值得聆听的声音。把它设为系统的文字转语音引擎，从屏幕阅读器到电子书应用再到聊天工具，凡是会朗读的应用都用 Marmalade 发声。</p>

<ul>
<li><b>自然的神经网络人声。</b>安装完即可开口朗读</li>
<li><b>反应迅速。</b>即使在配置一般的手机上也能很快出声</li>
<li><b>默认保护隐私。</b>所有处理都在设备本地完成</li>
<li><b>可选的云端人声。</b>使用你自己的 API 密钥接入注重隐私的第三方（Venice.ai）</li>
<li><b>为每个应用配音。</b>可以给不同应用分别指定声音</li>
<li><b>支持 8 种语言。</b>Kokoro 引擎会自动识别正在朗读的语言</li>
<li><b>无障碍友好。</b>完整支持 TalkBack，并按 WCAG 2.1 AA 标准设计</li>
<li><b>语音效果。</b>22 种效果预设，还带一个可自制效果的编辑器</li>
<li><b>免费、开源、无广告、无需注册账号</b></li>
</ul>

<p><b>处处都能用</b></p>
<p>Marmalade 实现了 Android 标准的文字转语音接口，可以直接替换 Google 或三星的 TTS。在设置里选一次，你所有应用的朗读都会由它接管。</p>

<p><b>开箱即用</b></p>
<p>应用内置了一把快速的英语人声，首次启动就能离线朗读。更大更好的引擎只在你选择时才会下载，而由设备本地人声朗读的文字永远不会离开你的手机。</p>

<p><b>每个应用都有自己的声音</b></p>
<p>Marmalade 以「别名」为核心。你可以调好语速和效果，组合出自己喜欢的声音。再把应用分配给不同的别名，电子书应用用一把声音，聊天应用用另一把。没有单独分配的应用则跟随你的主别名。</p>

<p><b>支持 8 种语言</b></p>
<p>多语言的 Kokoro 引擎支持英语（美国和英国）、西班牙语、法语、意大利语、葡萄牙语（巴西）、印地语、日语和中文普通话。它会在朗读过程中识别语言，并即时切换发音。</p>

<p><b>无论是否使用云端，都保护隐私</b></p>
<p>没有分析统计，没有遥测，不需要账号，我们也没有任何后台服务器。设备本地的人声只在你下载所选引擎时才会联网。如果你想要超出手机算力的声音，可以用自己的 API 密钥添加云端引擎。可选的服务商包括 Venice.ai，据其说明不会存储或记录请求。在你主动配置之前，你朗读的任何内容都不会离开手机。<i>注意：其他服务商可能会记录请求，请查阅它们的隐私政策。</i></p>

<p><b>为屏幕阅读器而生</b></p>
<p>Marmalade 无障碍体验完善，深度支持 TalkBack，并采用高对比度深色主题，按 WCAG 2.1 AA 标准设计。每个控件都有标签，开启 TalkBack 后进度和错误都会朗读播报。辅助技术用户需要的功能，没有一项被放在付费墙后面。</p>

<p><b>打造你的专属声音</b></p>
<p>22 种内置效果预设，例如 8-bit、cyborg、megaphone 和 vintage radio，让朗读更有个性。你也可以在编辑器里自行搭配效果链。</p>

<p><b>长文也能读完</b></p>
<p>前台播放服务可以在息屏状态下稳定朗读长篇文字，并支持锁定屏幕和蓝牙控制。你可以从任意应用分享文字过来，使用系统的「朗读所选内容」操作，或者通过快捷设置磁贴朗读剪贴板内容。</p>

<p><b>开源</b></p>
<p>Marmalade 自身的源代码采用 MIT 许可，代码仓库中不含任何 GPL 代码。发布版应用还包含在构建时从源码编译的 espeak-ng 音素转换器，因此你安装的这个应用是以 GPL-3.0-or-later 分发的。所用的 espeak-ng 版本在项目仓库中已固定，每个组件的许可详情都可以在应用内查看。</p>
