<p>Marmalade TTS 让你的手机拥有值得一听的声音。把它设为文字转语音引擎后，从屏幕阅读器、电子书阅读器到聊天应用，每个会朗读的应用都会通过 Marmalade 发声。自然的语音在你的手机上离线运行。</p>

<ul>
<li><b>自然的神经网络语音。</b>超过 70 个，安装后立即就有一个快速的英语语音可用</li>
<li><b>先试听再选择。</b>每个本机语音都能播放一段简短示例</li>
<li><b>快速。</b>即使在配置一般的手机上，也能很快开始朗读</li>
<li><b>默认私密。</b>一切都在你的设备上运行</li>
<li><b>按应用分配语音。</b>为每个应用指定专属语音</li>
<li><b>支持 9 种语言。</b>Kokoro TTS 会自动识别正在朗读的语言</li>
<li><b>无障碍。</b>支持 TalkBack，并按 WCAG 2.1 AA 标准设计</li>
<li><b>语音音效。</b>超过 20 个预设，外加可以自制音效的编辑器</li>
<li><b>可选云端语音。</b>来自 Venice.ai 等云端服务商，使用你自己的 API 密钥</li>
<li><b>免费、开源、无广告、无需账户</b></li>
</ul>

<p><b>支持 9 种语言</b></p>
<p>多语言引擎 Kokoro 会说英语（美式和英式）、西班牙语、法语、意大利语、葡萄牙语（巴西）、印地语、日语和普通话。它边读边识别语言，并即时切换发音。Kokoro German 还提供原生的德语语音。</p>

<p><b>随处可用</b></p>
<p>Marmalade 接入 Android 标准的文字转语音设置，所以任何通过这个设置朗读的应用，都会用 Marmalade 发声。在“设置”中把它选为 TTS 引擎，只需一次。</p>

<p><b>开箱即用</b></p>
<p>Marmalade 内置一个快速的英语语音，所以从第一次启动起，文字转语音就能离线使用。其他语言只需下载一次。更大、更好的引擎只在你选择时才下载，下载后同样离线运行。</p>

<p><b>每个应用都有自己的声音</b></p>
<p>Marmalade 围绕“别名”打造。用语速和音效设置搭配出你喜欢的语音，再把应用指向别名：电子书阅读器可以用一种声音朗读，聊天应用用另一种。未指定的应用都会使用你的主别名。</p>

<p><b>私密，用不用云端都一样</b></p>
<p>没有统计分析，没有遥测，没有账户，也没有我们自己的后端服务器。本机语音只在下载你选择的引擎时才会联网。如果你想要超出手机能力的语音，可以用你自己的 API 密钥添加云端服务商的语音。有些服务商（如 Venice.ai）表示不会存储或记录请求；其他服务商可能会记录，请查看它们的隐私政策。在你设置云端服务商之前，你朗读的任何内容都不会离开手机。</p>

<p><b>朗读网页</b></p>
<p>把链接分享给 Marmalade，它会用简洁的阅读模式打开文章，朗读时高亮当前段落。每篇文章都能选择由哪个语音朗读，以及读多快。只会访问你分享的那个页面，不加载图片或跟踪器，也不保存任何内容。</p>

<p><b>为屏幕阅读器而生</b></p>
<p>你可以把 Marmalade 用作 TalkBack 等屏幕阅读器背后的 TTS 引擎。应用本身支持 TalkBack，并按 WCAG 2.1 AA 标准设计，深色主题符合 AA 对比度要求。开启 TalkBack 时，进度和错误都会朗读出来。</p>

<p><b>打造你的专属声音</b></p>
<p>8-bit、Cyborg、Megaphone、Vintage radio 等超过 20 个内置音效预设，让朗读更有个性。你也可以在编辑器里搭建自己的音效链。语速可在半速到两倍速之间任意设置，语音依然保持自然。</p>

<p><b>长文也能读完</b></p>
<p>即使息屏，Marmalade 也会继续朗读长文本，并支持锁屏和蓝牙控制。从任意应用分享文本，或选中文字后选择“用 Marmalade 朗读”即可。</p>

<p><b>开源</b></p>
<p>Marmalade 自己的源代码采用 MIT 许可，不含任何 GPL 代码。发布的应用还包含从源代码编译的 espeak-ng 音素转换库，因此你安装的应用以 GPL-3.0-or-later 许可分发。每个组件的许可详情都可以在应用内查看。</p>
