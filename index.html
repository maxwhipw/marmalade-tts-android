Works everywhere

Marmalade implements Android's standard text-to-speech interface, so it is a drop-in replacement for Google or Samsung TTS.

1
InstallFrom F-Droid or the APK. A fast English voice is built in and works offline immediately.
2
Pick it onceSettings › Accessibility › Text-to-speech output › choose Marmalade.
3
Everything speaksScreen readers, e-readers, chat apps, browsers. Anything that reads aloud now uses Marmalade.

What you get

Everything runs on your device unless you decide otherwise.

  • Natural neural voices

    Ready to speak the moment you install. Bigger and better engines download only when you choose them.

  • Fast

    Speech responds quickly even on modest phones. Streaming synthesis starts talking before the sentence is done.

  • Private by default

    No analytics, no telemetry, no accounts, no backend of ours. Text read by on-device voices never leaves your phone.

  • A voice for every app

    Build aliases with a voice, speed, and effects. Route your e-reader to one and your chat app to another.

  • Speaks 8 languages

    The Kokoro engine detects the language as it reads and switches pronunciation on the fly.

  • Reads the web

    Share a link and Marmalade opens a clean reader view, then reads it aloud with the current paragraph highlighted.

  • Voice effects

    22 built-in presets plus an editor to build your own effect chains.

  • Accessible

    Rich TalkBack support, designed to meet WCAG 2.1 AA. Every control is labeled, progress and errors are announced.

  • Reads the long stuff

    Long text plays reliably with the screen off, with lock-screen and Bluetooth controls, a Quick Settings tile, and share-to-speak.

Private, with or without the cloud

On-device voices touch the network only to download the engines you pick. If you add a cloud engine, it uses your own API key with a provider you choose. Until you set one up, nothing you read ever leaves your phone.

Support development

Marmalade is free, with no ads, no accounts, and nothing an assistive-tech user needs behind a purchase. If it is useful to you, you can sponsor its development. Donations are voluntary and not tax-deductible.

Open source

Marmalade's own source code is MIT licensed and its repository contains no GPL code. The published app also contains the espeak-ng phonemizer, compiled from source at build time, so the app you install is distributed under GPL-3.0-or-later. The exact espeak-ng version used is pinned from the project repository, and license details for every component are shown inside the app.
