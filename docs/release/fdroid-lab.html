G4Versioning — DECIDED (1.0.0 + widened scheme, ABI reserved)done▸

Ship 1.0.0 (feature-complete; perpetual 0.x is a habit, not a rule). versionCode = MAJOR*10_000_000 + MINOR*10_000 + PATCH*10 + ABI → 1.0.0 universal = 10000000, ABI digit reserved from the start (0=universal … 4=x86_64, F-Droid sort order). Widened to 3-digit MINOR/PATCH so a long patch run can't collide (ceiling is 2.1e9, so free). Encode as a Gradle helper + comment; apply at the 1.0.0 cut, not now.

R — Reproducible builds (new workstream, decided: do it)

Near one-way door: Android forbids a signing-key change without reinstall, so RB can't be enabled after first publishing F-Droid-signed. Max: "do it right the first time." Payoff: F-Droid / GitHub / Obtainium share one signature and cross-update; higher supply-chain trust.
