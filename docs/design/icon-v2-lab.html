Locked decisions

✓ Eye-line anchor — the arcs align with the jar's eyes. ✓ 3 arcs. Both are baked in.

Why it read flat: the ramp interpolated linearly between two stops, which the eye reads as a even wash, and it bottomed out at #7C2D12. Now the gradient emits five stops shaped by a curve, the geometry is adjustable — linear at any angle, or radial from any point — and the ramp's dark end is selectable: deep amber #C2410C (default, the lightest floor), toast ink #7C2D12, or rich brown #422006 if you ever want it heavy. Still entirely locked-palette colours, starting from peach #FDBA74 through orange #F97316.

Notes

Portability: minSdk is 28. VectorDrawable supports linear and radial gradients with multiple stops, so everything here ports into ic_launcher_foreground.xml 1:1; a gradient background means the adaptive icon's <background> becomes a drawable instead of a colour resource. SVG drop-shadow filters do not port — the shadow here is a real offset duplicate path at low alpha, which does.
