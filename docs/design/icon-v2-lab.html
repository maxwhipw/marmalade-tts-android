Notes

Portability: minSdk is 28. VectorDrawable supports linear and radial gradients with multiple stops and strokes, so the gloss gradients, the sticker outline and the eye treatments all port into ic_launcher_foreground.xml 1:1. There is no blur — the drop shadow is built from offset silhouette copies at low alpha, which is why it reads as a soft stepped edge rather than a true gaussian. That's deliberate: it survives the port.
