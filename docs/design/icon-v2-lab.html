Locked decisions

✓ Eye-line anchor — the arcs align with the jar's eyes, not its geometric centre or mouth. ✓ 3 arcs. Both are baked in and no longer adjustable here.

On the background palette: the jar body is amber #F5A623, so any orange-family field will sit close to it — that's why the peach diagonal read as muddy. The palettes below win contrast one of two ways: value (dark grounds, keeping the marmalade hue family) or hue (a complementary/cool ground). The cool grounds leave the locked Marmalade scheme, which is a real brand call — they also separate hardest from the agent app, which is the whole point of this icon.

Notes

Portability: minSdk is 28, so vector gradients port straight into ic_launcher_foreground.xml; a gradient background means the adaptive icon's <background> becomes a drawable instead of a colour resource. SVG drop-shadow filters do not port — VectorDrawable has no filter support, so the shadow here is a real offset duplicate path at low alpha, which ports 1:1.
