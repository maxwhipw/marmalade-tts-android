What's actually wrong today

BASE below is traced from the shipped code, so it reproduces all three problems you spotted on device:

The three

1. Nothing is top-aligned. The row is verticalAlignment = CenterVertically and the spec column is Arrangement.Center, so on a tall card (Kokoro) the name and SPEED drift apart — neither column starts at the top.
2. The languages value is indented. EngineLanguagesValue carries padding(horizontal = 4.dp) for its touch target, so "English" / "See all 9" sit 4 dp right of Natural and Fastest. It's small but it breaks the column's left edge.
3. Both buttons are bunched right. The action row is Arrangement.End, so Uninstall sits next to Engine settings instead of anchoring the opposite corner.

Action row — where Uninstall goes

Three readings of "Uninstall left aligned", on the only card that has two buttons (Kitten, installed). The single-button cards keep their CTA right in all three.

Recommendation

C1 + action row A2

C1 is the brief applied straight: rule gone, both columns top-aligned, languages flush with the other spec values. SPEED now sits level with the engine name on every card, and the spec column's left edge is finally straight. C2 is the same with a wider gap if the columns read too close once the rule goes.

For the buttons, A2 (split) — Uninstall anchored left, Engine settings right — reads best: it separates the destructive action from the primary one instead of putting them a thumb-width apart, which is also the safer arrangement for a mis-tap. A3 (both left) keeps them adjacent and loses the primary action's usual right-corner home.

Also worth seeing: C5 (stacked) is the one genuinely different idea — specs become a full-width row under the text, so the description gets the whole card width. It's a bigger change than you asked for, but the extra description room is real. C3 (faint panel) and C4 (one-line specs) are the middle options if C1 feels too bare.

Scope for C1 + A2: in EnginesScreen.EngineCard the Row's verticalAlignment → Alignment.Top, drop the VerticalDivider + one Spacer; in EngineSpecColumn verticalArrangement → Arrangement.Top and drop the languages value's horizontal = 4.dp (keep the vertical padding so the touch target survives); in ActionRow the Installed branch → Arrangement.SpaceBetween. No string or behaviour changes.
