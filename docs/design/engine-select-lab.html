The problem

Today each engine is a paragraph. Max's read: people don't need to know a model uses espeak — they need speed (most of all), then quality, then languages. Every variation below leads with a speed signal, compresses quality + languages into scannable chips, drops the size to a small secondary number, cuts the technical talk, and hides the license behind a "show more". The default recommendation moves from Kokoro to Kitten Nano (the new fastest default), shown pre-selected. Same card design is meant to work on the Engines tab too.

Today — the wall of text

Reproduced from EngineCatalog.kt strings + OnboardingScreen.kt so the before/after is fair. Three cards, each ~6 lines of prose plus a two-line license blurb. Nothing is scannable; speed is buried inside sentences.

A1

Compact rows

Densest, most scannable. One tight row per engine: checkbox, name, a speed tier pill with a 3-bolt micro-meter on the right, then a single meta line (quality · languages · size). No paragraph at all — the whole list fits above the fold. Best fit for the Engines tab where the list may grow.

For

Fastest to scan; three engines read in ~2s. Speed is the loudest element on every row. Scales to more engines without pushing Install off screen.

Against

Least room for personality — no space for the mascot moment, and the "why" behind each engine is compressed to a few words.

A2

Speed gauge

Speed as the hero. Each card's dominant element is a full-width segmented speed gauge with the tier label above it and a one-line plain-English caption below ("Several× faster than real time — even on old phones"). Quality + language ride as small chips; size is a mono number in the corner. License is a "show more" disclosure.

For

Most unambiguous about the single most important axis — the gauge is impossible to miss and the caption answers "what does that mean for me?".

Against

Tallest of the four; three cards + Install just fit a short phone. The gauge is decorative weight if the user already knows what they want.

A3

Spec columns

Reads like a comparison table. Left side is name + one honest line of prose; a fixed right-hand column stacks the three axes as labeled stats — SPEED (big, with a mini meter), QUALITY, LANGUAGES — always in the same place so the eye can compare straight down the list. Size sits with the name.

For

Best for deciding between engines: the stats align in a column so you compare speed-to-speed, langs-to-langs without re-reading. Feels precise.

Against

Most "spec sheet", least warm — the fixed column is a bit rigid for a friendly onboarding, and the narrow column truncates longer values.

A4

Hero speed badge

Playful, glanceable. A big rounded speed "badge" tile leads each row like an avatar — bolts + the tier word (FASTEST / FAST / HEAVY) — with name, quality and language stacked to its right and size tucked small. The badge does the 2-second job; everything else is support.

For

Warmest + most on-brand — the badge is a friendly object, not a data readout, and pairs well with the jar mascot. Speed still wins the glance.

Against

The badge spends horizontal room on a label; less space for the quality/language nuance than A2/A3. "HEAVY" as a badge could read as a warning if not styled warm.

Notes for review

  • Recommendation flip. Every mockup shows Kitten Nano as the pre-selected "recommended" engine (it's Kokoro today in EngineCatalog.kt — isRecommended). Flipping that flag + updating the pre-select set is the code change the design assumes.
  • Orange stays precious. The one orange on each light frame is the Install CTA. Speed meters use Peach so a screen full of filled meters never floods with accent — per marmalade-design-scheme-v0. In dark mode there is no orange anywhere (Install = rich brown).
  • No green/red. "Heavy" is not a failure — Pocket is the expressive pick. Tiers are encoded by meter fill + label, not by traffic-light colour, to stay on-palette and avoid framing Pocket as "bad".
  • License. Shown only behind "show more" (A1/A2) or omitted entirely (A3/A4) — it also lives in Settings → About → Licenses, so the screen doesn't have to carry it.
  • Same card, two homes. A1 is the most natural fit for the Engines tab (dense list); A2/A4 are more onboarding-flavoured. A3 works in both.
  • Fonts. Rendered with system fonts (no CDN) — the wordmark is styled, not Momo Trust Display. For pixel-exact brand type, drop in the Google Fonts link used by speak-screen-lab.html.
