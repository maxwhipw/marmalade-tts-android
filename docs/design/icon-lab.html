The problem

The TTS launcher icon and the marmalade agent app icon are the same art: the kawaii jar on the same orange #F97316 field. On a home screen or dock they are indistinguishable at a glance. Goal: keep the jar mascot Max likes, but give the TTS icon a voice identity (speaking / sound) and optionally its own background field so it separates on the shelf.

Two levers, combinable: the mark (what the jar is doing — V-variants below) and the field (background color — B-swatches). Changing the field alone is the strongest at-a-glance separator; changing the mark alone keeps both apps orange but makes the TTS jar recognizably "the speaking one".

B — background field

Pick a field; every variant below re-renders on it. B0 is the current orange — the one the agent app also uses. All alternatives are from the locked Marmalade palette (no new shades).

V — mark variants

Each card shows the full 108-canvas, the circular launcher mask (center 72 of 108 — what most launchers actually display), and shelf size. Download gives the full-canvas SVG on the selected field.

2026-08-01: V2 (sound waves) is the provisional pick. V5a–V5c explore the speech-bubble concept with happier :D faces per Max's feedback.

Shelf test

Everything at 48 px next to the agent icon — the actual decision distance. If a variant doesn't separate here, it doesn't separate.

Decision + export

Once a winner is picked:

# 1. Download the winning SVG from its card (e.g. V3-B1.svg)
# 2. Play Store icon (512, bg baked in):
inkscape V3-B1.svg -w 512 -h 512 -o docs/release/play-assets/icon-512.png
# 3. Adaptive launcher icon:
#    - background: app/src/main/res/values/colors.xml → ic_launcher_background
#    - foreground: port the mark's paths into a new drawable (same coordinate
#      space as mascot_happy.xml — the SVG paths transfer 1:1, only
#      #AARRGGBB alpha notation differs)
# 4. fastlane/metadata/android/en-US/images/icon.png gets the same 512 render
