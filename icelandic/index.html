Icelandic voice review — marmalade-tts

We're adding four Icelandic voices trained from scratch on the Talrómur corpus (CC BY 4.0) — recorded in a soundproof RÚV studio by Reykjavík University for the Icelandic Language Technology Programme. None of the maintainers speak Icelandic, so before these ship we'd like native speakers to listen and tell us what's good enough. All audio below is synthesized on-device-equivalent output from marmalade-tts's VITS engine.

How to give feedback: comment on issue #1. Most useful: which sample ids sound wrong and what is wrong (mispronounced word, weird rhythm, wrong stress), an overall 1–5 naturalness rating per voice — and better test sentences than these (this is a small starter set written by non-speakers; corrections welcome).

Questions for reviewers

  1. Naturalness 1–5 per voice? Any mispronounced words (sample # + word)?
  2. Would you use your favourite of these as a daily read-aloud voice?
  3. Are the test sentences themselves wrong anywhere? Suggest better ones.
  4. Anything Icelandic-specific we should test (numbers, dates, names, dialect)?
