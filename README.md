# Language review branch

Audio samples and status pages for adding new languages to marmalade-tts.
This branch is intentionally separate from the app source so the audio files
don't weigh down normal clones.

- **[Language support status](LANGUAGES.md)** — where each requested language stands.
- **[German voice review](german/)** — samples for German speakers to evaluate.
